# SoloHost Pi Network Static UI — Change Report

## Added
- Added a `Pi Network · SoloHost` option to the static-site template selector.
- Added a responsive, mobile-first Pi Network community landing page template generated by the Hub.
- Included inline CSS and a small inline language toggle (English/Vietnamese); no CDN or external assets are required.
- The template explains static hosting and explicitly notes that it does not require a child container or container isolation.
- Escapes the user-supplied app name before inserting it into the HTML title/header.

## Preserved
- Existing Pioneer, blank, paste-HTML, ZIP-upload, and dynamic Node/Python templates.
- Existing app management, logs, ledger, mesh, flow, preview, and API behavior.
- No container isolation mount, privileged mode, or additional runtime service was introduced.

## Verification
- `node --test 'scripts/**/*.test.mjs'`: 188 passed, 0 failed.
- `npm run build`: blocked because local Vite executable/dependencies are missing. The existing `with-app-env` guard reports `PREVIEW_DEPENDENCY_MISSING`; no source change was made to bypass it.
- Docker image build and live SoloHost deployment were not run in this environment.
